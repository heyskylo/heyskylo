# Nyxian ROM skeleton

Generated by `nxromgen.sh` from a Nyxian checkout.

## Build

    make
    make clean

`make` produces `rom.zip` — a single ROM archive the Nyxian bootloader
flashes into `Library/Boot/Slot/A`.

## ROM manifest

The bootloader (`Nyxian/UI/BootViewController.swift` in the Nyxian source)
does **not** read the legacy `manifest.sign` line-list. After extraction it
reads `manifest.plist` at the slot root and requires these keys:

| Key                          | Type     | Meaning                                        |
| ---------------------------- | -------- | ---------------------------------------------- |
| `NXRomManifestVersion`       | Int      | Manifest ABI. Must be `1`.                     |
| `NXRomIdentifier`            | String   | Reverse-DNS identifier of the ROM.             |
| `NXRomName`                  | String   | Display name shown by the bootloader.          |
| `NXRomVersion`               | String   | Version string shown by the bootloader.        |
| `NXRomMinimumNyxianVersion`  | String   | Minimum Nyxian version the ROM needs.          |
| `NXRomExecutable`            | String   | Slot-relative Mach-O to `dlopen`. Must export `NXSlotMain`. |

Optional keys: `NXRomDefaultFilePermission` (default `420`), `NXRomDefaultDirectoryPermission`
(default `493`), `NXRomPaths`, `NXRomInstaller`, `NXRomUninstaller`, `NXRomBootLogo`.
NXRomPaths entries may request re-signing at flash (`NXRequiresCodeSigning`) plus
Nyxian NXT2 entitlements (`NXT2Entitlements`).

Current manifest contents:

- `main` — the slot host image, `0755`, re-signed at flash.
- `Application/Hello.app/Hello` — the shipped guest app, `0755`, re-signed at flash.

Validate it with `make validate` (runs `plutil -lint` and checks every
required key against what the bootloader parses).

## Note on signing

`NXRequiresCodeSigning = true` means the bootloader re-signs those Mach-O
images during flashing with the certificate imported into Nyxian (Settings →
Signing, same certificate LiveContainer uses). iOS only loads validly-signed
Mach-O, so flashing without an imported certificate fails on purpose. To ship
a ROM that flashes without re-signing, set `NXRequiresCodeSigning` to `false`
(and be ready for the kernel to reject unsigned images at boot).
